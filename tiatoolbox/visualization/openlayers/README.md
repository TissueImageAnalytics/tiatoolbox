# 6. OpenLayers frontend

This folder contains the source code and build setup for the TIAToolbox
OpenLayers viewer.

## Normal users

Normal TIAToolbox users do not need Node.js, npm, Vite or `node_modules`.

The generated JavaScript and CSS files are included in the Python package, so
TIAToolbox can be installed and the OpenLayers viewer can be used through the
existing `show-wsi` command as usual.

The npm/Vite setup described below is only required when developing or
rebuilding the OpenLayers frontend.

## Running the viewer

`show-wsi` starts the TIAToolbox viewer for a whole slide image and any
additional overlays provided.

Run `show-wsi` with the path to a slide from the root of the TIAToolbox repository:

```bash
tiatoolbox show-wsi --img-input /path/to/slide.svs
```

Multiple image paths can also be provided to display a slide together with
additional layers.

## For Developers

Node.js and npm are required when changing or rebuilding the OpenLayers frontend.

Check that they are installed with:

```bash
node --version
npm --version
```

The frontend files are:

- `package.json` defines the frontend dependencies.
- `package-lock.json` records the exact dependency versions installed by npm.
- `src/main.js` contains the OpenLayers viewer code.
- `src/style.css` contains the viewer styling.
- `vite.config.js` defines how the frontend is built.

The generated files are:

```text
tiatoolbox/data/visualization/static/openlayers/viewer.js
tiatoolbox/data/visualization/static/openlayers/viewer.css
```

These are the files Flask serves when `show-wsi` is used.

Run the following commands from:

```text
tiatoolbox/visualization/openlayers/
```

Install the dependencies with:

```bash
npm ci
```

This installs the exact versions recorded in `package-lock.json`.

After changing `src/main.js` or `src/style.css`, rebuild the frontend with:

```bash
npm run build
```

This updates `viewer.js` and `viewer.css`.

The generated files should be committed with the source changes.

Do not edit `viewer.js` or `viewer.css` directly because they are generated by
Vite.

After rebuilding the frontend, return to the root of the TIAToolbox repository
and run `show-wsi` as usual:

```bash
tiatoolbox show-wsi --img-input /path/to/slide.svs
```

The viewer will use the newly generated viewer.js and viewer.css files.

If the OpenLayers or ol-ext version needs to be changed, update it with npm and
then rebuild the frontend in the openlayers directory. For example:

```bash
cd tiatoolbox/visualization/openlayers/
npm install --save-exact ol@<version>
npm run build
```

This updates the recorded dependency version and rebuilds viewer.js and viewer.css using the new version.
